## Files in this recipe

- `House_Prices_Prediction_using_TFDF.ipynb`: Notebook containing the data preparation, TensorFlow Decision Forests model, and prediction workflow.
- `submission.csv`: Sample predictions generated by the model.
- `Dataset/`: The training data, test data, and feature description.
