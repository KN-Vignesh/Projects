# Titanic Model 🚢

This recipe contains the code and resources for the classic Titanic machine learning problem.

## Overview
This project involves exploratory data analysis (EDA) and predictive modeling to determine which passengers survived the Titanic shipwreck based on passenger data (ie name, age, gender, socio-economic class, etc).

## Files in this recipe
- `Titanic_model.ipynb`: Jupyter notebook containing the full EDA, feature engineering, and model training workflow.
- `submission.csv`: Sample predictions generated by the model.
- `Dataset/`: The training and testing datasets.

## How to use
To explore the analysis and modeling, check out the notebook locally or view it on GitHub. Docsify renders Markdown, so the notebook is available in the repository files!
