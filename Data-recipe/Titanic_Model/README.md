## THE PROBLEM

Real-world tabular data requires exploration before modelling. Missing values, feature quality and assumptions about the target all influence the resulting system.

## THE APPROACH

The project uses the Titanic dataset to move through exploratory analysis, feature engineering and predictive modelling for passenger survival.

## THE SYSTEM

**Raw passenger data → exploration → feature engineering → classification model → predictions → submission.**

## IMPLEMENTATION

The repository contains the full notebook, training and test datasets, and a sample submission output.

## WHAT THIS PROJECT DEMONSTRATES

**EDA, feature engineering, supervised classification and the foundational workflow that later deep-learning and AI systems build upon.**
