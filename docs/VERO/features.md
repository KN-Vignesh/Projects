# Features

## Pull request analysis

Enter a public GitHub pull request URL or select one of the built-in examples. VERO supports standard GitHub pull request URLs and repository-number shorthand through its URL parser.

## Evidence and policy

Findings retain their source, rule identifier, severity, file, line, and remediation guidance. Static vulnerabilities can override a low model-risk signal, while corroborating signals can raise the review requirement.

## Review workflow

The interface includes an interactive diff inspector, analysis history, a 24-hour anonymous trial quota, token settings, an engineering journey, benchmark data, and Markdown report export.

## Evaluation

The evaluation view compares Jev-only, static-only, and combined configurations, including documented disagreement scenarios. Reported provider figures are kept separate from project-measured values.
